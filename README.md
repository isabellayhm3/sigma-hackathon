# Solar Panel Reliability & Quality Control Dashboard

Our R-based tool analyzes solar farm performance data to identify shading and degradation issues using real-time statistical analysis.

## Features
- Computes voltage, current, and power statistics per hour.
- Classifies shading vs. degradation using group variance and z-score logic.
- Assigns a 0–1 health score to each panel.
- Interactive Shiny dashboard for visualization and analysis.

## Installation
1. Clone this repository
2. Open in RStudio or Posit Cloud
3. Run `app.R`

## Project Structure
See `/code` for analysis scripts and `/data` for example datasets.
